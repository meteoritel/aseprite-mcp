# 领域文档

## 布局与读取

本仓库采用 single-context 布局：

- 根目录 `GLOSSARY.md` 保存领域术语。
- `docs/adr/` 保存架构决策，文件名采用 `0001-<decision-slug>.md` 格式。

探索代码前，读取已有术语表和与当前工作相关的 ADR。文件缺失时继续探索；术语或决策确认后，由 `/domain-modeling` 按需创建。

## 使用术语

Issue 标题、设计建议、假设和测试名称使用术语表中定义的名称。遇到尚未定义的概念时，核对项目现有用语，并将确需补充的术语交由 `/domain-modeling` 整理。

## 决策冲突

建议与已有 ADR 冲突时，明确指出对应 ADR、冲突内容及重新讨论的理由。
